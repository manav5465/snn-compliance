## Purpose

SNN Compliance is a professional compliance and certification consultancy helping manufacturers, importers, exporters and brands obtain regulatory approvals and certifications for Indian and International markets.

The website should build trust, showcase expertise, explain services clearly, and generate qualified business leads.

Overall design should feel:

- Premium
- Corporate
- Modern
- Clean
- Trustworthy
- Technology Driven

Avoid flashy animations.

Think Deloitte, EY, KPMG, BSI, SGS, TÜV SÜD style websites.

# Code Standards

Always write reusable React components.

Use functional components only.

Use Tailwind utility classes.

Avoid inline styles.

Keep components modular.

Create reusable sections.

Maintain consistent spacing.

Use semantic HTML.

Lazy load heavy assets.

Optimize images.

Follow accessibility best practices.
